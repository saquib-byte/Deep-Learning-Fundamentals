# My Deep Learning Fundamentals Notes

This repository is my personal fork of the [Microsoft AI-For-Beginners](https://github.com/microsoft/AI-For-Beginners) course. 
I am using this to track my progress and keep my interactive notebooks in sync with Google Colab.

## My Workflow
1. **Never edit the original notebooks directly!** To avoid merge conflicts if Microsoft updates the curriculum, always duplicate a notebook before working on it (e.g., duplicate `lesson.ipynb` to `lesson_my_practice.ipynb`).
2. **Commit and Push:** After working locally or in Colab, always `git commit` and `git push` to save progress to this GitHub fork.
3. **Open in Colab:** You can open your synced notebooks in Google Colab directly by navigating to `https://colab.research.google.com/github/saquib-byte/Deep-Learning-Fundamentals`.

## Local Sparse Checkout
Note: This local clone is configured using Git Sparse-Checkout to **exclude** translation folders (like `zh-cn`) to save space. When you push, it will not delete those folders on the GitHub repository.
